# U2-ejercicio24
### Motores de Base de Datos Intercambiables

**Objetivo principal:** Implementar un sistema modular de conexión a diferentes motores de bases de datos utilizando interfaces, abstracción y polimorfismo en Java.

El ejercicio consiste en desarrollar una interfaz `ConexionBD` que establece operaciones comunes de conexión, ejecución de consultas y desconexión. Se implementan las clases `ConexionMySQL`, `ConexionPostgreSQL` y `ConexionMongoDB`, incorporando validaciones para controlar el estado de las conexiones y evitar operaciones cuando la base de datos no se encuentra conectada.

**Conceptos aplicados:** Interfaces, abstracción, implementación, polimorfismo, encapsulamiento, modularidad y validaciones de estado.
